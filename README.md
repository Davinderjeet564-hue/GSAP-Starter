# GSAP Starter

A beginner-friendly project demonstrating animation control using GSAP (GreenSock Animation Platform).

## Features

- **Play** - Start the animation
- **Pause** - Pause the animation mid-sequence
- **Restart** - Reset and replay the animation

## Usage

Click the control buttons to manage the animation playback.

## Tech Stack

- GSAP
- HTML5
- CSS3
- JavaScript
